## 코드

인라인 코드는 `const a = 1;` 처럼 씁니다. 여러 줄은 코드블록으로 씁니다.

```javascript
function greet(name) {
  return `안녕하세요, ${name}!`;
}

console.log(greet('블로그'));
```

## 표

| 문법 | 결과 | 비고 |
| --- | :---: | ---: |
| `**굵게**` | **굵게** | 강조 |
| `*기울임*` | *기울임* | 보조 |
| `~~취소선~~` | ~~취소선~~ | 삭제 |
